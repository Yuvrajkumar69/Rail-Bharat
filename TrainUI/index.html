ABOUT RAIL BHARAT

Built for a smooth railway experience.

Rail Bharat is a Java full-stack railway reservation project powered by Spring Boot, JPA and MySQL with a responsive web frontend. The application handles train search, seat availability, booking, PNR lookup and contact requests through REST APIs.
